# Ronak Jain Portfolio

A warm, claymorphic single-page portfolio built with pure **HTML + CSS + JavaScript**.

## Sections

- Hero
- About
- Projects (clickable GitHub repo cards)
- Stack / Tools
- Contact

## Tech

- HTML5 (semantic structure)
- CSS3 (custom properties, Grid, Flexbox, animations)
- Vanilla JavaScript (scroll reveals, copy-email, nav scroll state)

## Run locally

Open `index.html` in your browser.

### View Portfolio
[Open Directly](https://ronak-jain-afk.github.io/RonaksPortfolio/)  


## Files

- `index.html` - page structure and content
- `styles.css` - design system and layout styling
- `script.js` - interactions
